# 📶 Digital Signal Processing (DSP)

This repository contains practical implementations and academic exercises developed during the Signal Processing course at **UNICAMP**. The focus is on analyzing, transforming, and filtering digital signals using Python and Jupyter Notebooks.

## 📝 Topics Covered

Each file focuses on a core concept of DSP, ranging from time-domain sampling to frequency-domain analysis.

### 🔬 Core Exercises

1. **[Signal Sampling & Aliasing](01-signal-sampling.py)**
   - Analysis of the Nyquist-Shannon Sampling Theorem.
   - Demonstration of aliasing effects when sampling requirements are not met.

2. **[Z-Transform Analysis](02-z-transform-analysis.ipynb)**
   - Evaluation of Linear Time-Invariant (LTI) systems.
   - Mapping poles and zeros to determine system stability and frequency response.

3. **[Discrete Fourier Transform (DFT/FFT)](03-discrete-fourier-transform.ipynb)**
   - Implementation of DFT and Fast Fourier Transform (FFT) algorithms.
   - Spectral analysis of periodic and non-periodic signals.

4. **[Digital Filter Design](04-digital-filter-design.ipynb)**
   - Implementation of FIR (Finite Impulse Response) and IIR (Infinite Impulse Response) filters.
   - Windowing techniques and frequency-domain filtering.

5. **[Spectral Analysis & Windowing](05-spectral-analysis.ipynb)**
   - Advanced spectral estimation and the impact of different window functions (Hamming, Hann, etc.) on frequency resolution.

## 🛠️ Tools & Libraries
- **Python 3.x**
- **NumPy & SciPy:** For numerical computation and signal processing functions.
- **Matplotlib:** For time-series and frequency-domain visualization.
- **Jupyter Notebook:** Interactive environment for documentation and code execution.
